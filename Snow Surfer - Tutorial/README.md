# Snow Surfer

A 2D physics-based arcade game built in Unity where the player surfs across snowy terrain, avoids obstacles, and scores points through momentum and movement.

## Gameplay

* Traverse snowy hills using physics-based movement
* Avoid obstacles and crashes
* Build momentum to travel farther
* Score points while surviving the terrain

## Features

* Physics-based player movement
* Particle systems
* Unity Input System
* Scene Management
* Scriptable Objects
* Dynamic terrain interaction
* Score tracking system
* Power-up Boosts to increase speed and torque

## Built With

* Unity
* C#
* TextMesh Pro

## What I Learned

This project helped me practice:

* Unity physics and torque mechanics
* Scene loading and management
* Using Scriptable Objects
* Unity's New Input System
* Particle effects
* UI and score systems
* Organizing game systems and scripts

## How to Run

1. Clone the repository
2. Open the project in Unity Hub
3. Open the project folder
4. Run the game from the Unity Editor
