# Unity 2D Practice Projects

Collection of mini games and practice projects built while learning Unity and C#.

## Projects

### Delivery Dash
Top-down food delivery game.

Features:
- Physics movement
- Camera follow
- Collision handling

### Snow Surfer
Arcade-style snow surfing game with physics-based movement and scoring mechanics.

Features:
- New Input System
- Particle Systems
- Scene Management
- Scriptable Objects
